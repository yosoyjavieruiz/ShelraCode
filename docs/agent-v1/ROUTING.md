# Capability-aware routing

Routing applies privacy and cost hard gates before quality. Local candidates
remain first-class. `strict-zero` never selects an unverified paid route.

For coding, the router first requires the candidate's measured capability to
meet the task role. Bounded single-file work can use a measured
`workspace_reader` route because the host stages one target and verifies it;
complex refactors and multi-file tasks require `advanced_coding_agent`. There
is no silent downgrade from an advanced task to a read-only or unmeasured
route. A blocked task with no mutation may escalate to another eligible
candidate; a task that already mutated the workspace never silently changes
models.

Hardware fit answers “can it run?”; capability probes answer “can it behave?”
Both are required for an autonomous coding label.
