# Final UI V3 evidence set

These are deterministic OpenTUI character-frame captures generated from the current source with `scripts/capture-ui.ts` at 80×24, 100×30, 120×40, 160×50, and 200×60.

The `conversation`, `models`, `settings`, `diff`, `provider-error`, and `palette` folders use explicit `LOCALCODE_UI_FIXTURE` data for repeatable visual review. Fixture mode is not loaded in a normal launch. The separate PTY evidence is the current bundled `dist/index.js` journey, not a fixture.
