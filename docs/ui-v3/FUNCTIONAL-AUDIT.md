# LocalCode UI V3 functional audit

Date: 2026-08-23. Findings are classified by user impact. `verified_local` means the current checkout produced the evidence; it does not mean production cutover or provider availability.

## Fixed in the rebuild

| Priority | Finding                             | Evidence before                                                 | Current correction                                                                                                               | Status                                                                             |
| -------- | ----------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| P1       | Startup cancellation race           | `runTask` assigned `activeTaskAbort` after awaited imports      | AbortController is created before the first await and cleared only for the matching task                                         | verified_local by source inspection and test suite                                 |
| P1       | Palette frame ownership             | Baseline palette frames merged landing text into rows           | Overlay hides the shell, uses an opaque root layer, and computes a bounded panel                                                 | verified_local in `tests/integration/tui-v3-overlay.test.tsx` and rebuild captures |
| P1       | Composer hidden by streaming growth | Streaming state could push the composer footer out of the frame | Streaming is part of the ScrollBox transcript and compact streaming mode reserves the composer                                   | verified_local in `states-v6/streaming/80x24.txt`                                  |
| P1       | Wrong provider recovery action      | Provider error directed users to model switch for health retry  | `Retry provider health` is a real command; local fallback remains `Ctrl+X M`                                                     | verified_local in registry/source and provider-error capture                       |
| P1       | Unsafe raw protocol output          | Model result could render JSON tool-request payload directly    | Presentation sanitizes protocol-shaped assistant output and caps displayed length; raw text remains in the stored event boundary | verified_local by source and full tests                                            |
| P2       | Draft lost when opening palette     | Ctrl+P cleared composer value and Escape did not restore it     | Palette stores a draft and restores it on cancel                                                                                 | verified_local by source path; interactive journey remains in final PTY audit      |
| P2       | Narrow picker collision             | Provider metadata collided with model labels at 80 columns      | Narrow picker uses two-line rows, truncation, and a bounded panel                                                                | verified_local in `model-picker` captures and component tests                      |
| P2       | Settings mutation rollback          | Persistence failure left in-memory values changed               | Persisted policy values restore the previous state on error; density/motion are explicitly session-only                          | verified_local by source; persistence failure injection remains a future test      |
| P2       | Non-focusable selection rows        | Mouse handlers existed without a keyboard activation contract   | Selectable rows, activity rows, and palette rows are focusable with Enter/Space contracts                                        | verified_local by source and component tests                                       |
| P2       | Transcript review                   | Hidden scrollbar and no focused viewport                        | ScrollBox is focusable with PageUp/PageDown and Ctrl+Up/Down hints                                                               | verified_local by source; real PTY scroll remains final acceptance work            |

## Required functional journey

The final audit must exercise: startup, compose, multiline input, submit, streaming, cancel, tool grouping/expansion, scroll review, Ctrl+P search/execute/Escape, model picker selection/Escape, providers and health retry, routing, settings mutation and failure rollback, sessions restore, diff, approval fixture, error recovery, resize, `NO_COLOR`, Ctrl+C, and terminal restoration.
